# Working drafts (Phase 0)

These are the per-area specification drafts the build is executed from, plus the verified-facts
files (claims with documentation URLs) and the review findings that override the drafts where they
conflict. Precedence when two documents disagree: `review-findings.md` > `contract.md` > the area
draft > `conventions.md`.

They are superseded by the final documentation in `docs/` once the corresponding phase lands.
