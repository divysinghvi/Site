## PromQL language (docs/querying/basics.md, operators.md, functions.md + parser/engine source)

| Fact | Source |
|---|---|
| Matchers `=`, `!=`, `=~`, `!~`; "Regex matches are fully anchored. A match of `env=~"foo"` is treated as `env=~"^foo$"`"; RE2 syntax | https://raw.githubusercontent.com/prometheus/prometheus/main/docs/querying/basics.md |
| Anchoring in source: `regexp.Compile("^(?s:" + re + ")$")` | https://raw.githubusercontent.com/prometheus/prometheus/main/model/labels/regexp.go |
| Empty-value matchers also match series without the label; multiple matchers per label allowed; "Vector selectors must either specify a name or at least one label matcher that does not match the empty string"; `__name__` matcher, any operator | basics.md |
| Range selector: "left-open and right-closed interval" — samples at the left boundary excluded, right boundary included | basics.md "Range Vector Selectors" |
| Durations: units `ms s m h d w y`; "Units must be ordered from the longest to the shortest. A given unit must only appear once"; `1h30m`, `12h34m56s`, `54s321ms` valid; `1.5h`, `0xABm`, `+Infd` invalid; a bare number in brackets is seconds | basics.md "Float literals and time durations" |
| `model.ParseDuration`: `"0"` allowed, units map `ms,s,m,h,d(24h),w(7d),y(365d)` with descending-order check; errors `not a valid duration string: %q`, `unknown unit %q in duration %q`, `duration out of range`; `Duration.String()` prints `y`/`w` only when exact (so `7d` prints as `1w`, `90s` as `1m30s`) | https://raw.githubusercontent.com/prometheus/common/main/model/time.go |
| Staleness/lookback: "taking the newest sample that is less than the lookback period ago. The lookback period is 5 minutes by default" (`--query.lookback-delta`, per-query `lookback_delta`); source: `defaultLookbackDelta = 5 * time.Minute`; selector picks sample with `t <= refTime` and `t > refTime - lookbackDelta` | basics.md "Staleness"; engine.go (`vectorSelectorSingle`) |
| Range query evaluation loop: `for ts := start; ts <= end; ts += interval` | engine.go |
| Precedence high→low: `^`; `* / % atan2`; `+ -`; `== != <= < >= >`; `and unless`; `or`; left-assoc except `^` right-assoc; yacc: `%left LOR / %left LAND LUNLESS / %left EQLC GTE GTR LSS LTE NEQ / %left ADD SUB / %left MUL DIV MOD ATAN2 / %right POW`; unary has `%prec MUL` | https://raw.githubusercontent.com/prometheus/prometheus/main/docs/querying/operators.md ; https://raw.githubusercontent.com/prometheus/prometheus/main/promql/parser/generated_parser.y |
| Arithmetic: IEEE 754 incl. NaN/±Inf; scalar/scalar, vector/scalar (applied to every sample), vector/vector one-to-one; "In any arithmetic binary operation involving vectors, the metric name is dropped" | operators.md |
| Comparison: filter by default; `bool` returns 0/1; "Between two scalars, the bool modifier must be provided"; with `bool` the metric name is dropped; without `bool` the LHS metric name is retained | operators.md |
| One-to-one matching: "Two entries match if they have the exact same set of labels and corresponding values" (`__name__` excluded from the signature: `names = append([]string{labels.MetricName}, names...)` in the `without` signature path) | operators.md; engine.go |
| Duplicate-signature errors (execution): `found duplicate series for the match group %s on the %s hand-side of the operation: [%s, %s];many-to-many matching not allowed: matching labels must be unique on one side`; `multiple matches for labels: many-to-one matching must be explicit (group_left/group_right)` | engine.go |
| Vector/scalar ops: name dropped when `changesMetricSchema(op)` (ADD SUB DIV MUL POW MOD ATAN2) or `returnBool`; comparisons without bool keep the vector's value and name even when the scalar is on the left | engine.go (`VectorscalarBinop`, `changesMetricSchema`) |
| Element ops: `+ - * /` native float ops, `^`=`math.Pow`, `%`=`math.Mod`, comparisons keep LHS value with `keep` flag | engine.go (`vectorElemBinop`, `scalarBinop`) |
| Aggregations `sum avg min max count ...`; syntax `<aggr-op> [without\|by (<label list>)] ([parameter,] <vector expression>)` or clause after; trailing comma allowed; `without` removes listed labels (and `__name__`), `by` keeps only listed labels; no clause → all dimensions | operators.md; engine.go (`generateGroupingLabels`) |
| `min`/`max`: "NaN is only ever considered a minimum or maximum if all aggregated values are NaN" (`if group < f \|\| math.IsNaN(group) { group = f }`) | operators.md; engine.go |
| Function signatures (ArgTypes): `abs ceil floor` (vector); `round` (vector, scalar; Variadic 1); `clamp_min clamp_max` (vector, scalar); `rate increase irate delta *_over_time` (matrix); `time()` (none → scalar); `vector` (scalar → vector); `scalar` (vector → scalar) | https://raw.githubusercontent.com/prometheus/prometheus/main/promql/parser/functions.go |
| `extrapolatedRate` algorithm (full code captured): Δ = last − first (+ previous value on each counter reset when isCounter); `durationToStart=(firstT−rangeStart)/1000`, `durationToEnd=(rangeEnd−lastT)/1000`, `sampledInterval=(lastT−firstT)/1000`, `avg=sampledInterval/(n−1)`, `threshold=avg*1.1`; single sample → no result; `if durationToStart >= threshold { durationToStart = avg/2 }`; counters: `durationToZero = sampledInterval*(first/Δ)` when Δ>0 and first≥0, `if durationToZero < durationToStart { durationToStart = durationToZero }`; `if durationToEnd >= threshold { durationToEnd = avg/2 }`; `factor=(sampledInterval+durationToStart+durationToEnd)/sampledInterval`; rate: `factor /= range.Seconds()`; result `Δ*factor` | https://raw.githubusercontent.com/prometheus/prometheus/main/promql/functions.go |
| `rate`: isCounter=true,isRate=true; `increase`: true,false; `delta`: false,false; `irate`=`instantValue(isRate=true)`: last two samples, needs ≥2, on reset (`last < prev`) uses last value, divides by their interval in seconds | functions.go |
| `round(v, to_nearest=1)`: `math.Floor(f*(1/toNearest)+0.5)/(1/toNearest)`; ties round up | functions.go; functions.md |
| `clamp_min`: `max(v,min)` (via `clamp(vec,min,+Inf)`), `clamp_max`: `min(v,max)`; NaN argument → NaN; docs special cases | functions.go; https://raw.githubusercontent.com/prometheus/prometheus/main/docs/querying/functions.md |
| `time()` = `float64(enh.Ts)/1000` (evaluation time, not wall clock); `vector(s)` = one sample with empty labels; `scalar(v)` = value if exactly one float sample else NaN | functions.go; functions.md |
| `*_over_time`: sum (Kahan), avg (Kahan, sum/count), min/max (NaN only if all NaN), count (number of samples), last (most recent sample, **keeps the metric name**); other float functions and aggregations drop `__name__` | functions.go (`funcLastOverTime` returns `el.Metric`); verified by execution |
| Parser error format: `"%s: parse error: %s"` where position = `line:col` (1-based) of the offending token, or `unknown position` when the query is empty | https://raw.githubusercontent.com/prometheus/prometheus/main/promql/parser/parse.go ; https://raw.githubusercontent.com/prometheus/prometheus/main/promql/parser/posrange/posrange.go |
| "unexpected" errors: `unexpected <desc>[ in <context>][, expected <x>]`; desc renderings: `end of input`, `identifier "x"`, `number "5"`, `string "s"`, `duration "5m"`, keywords `<bool>`, operators `<op:*>`, aggregators `<aggr:sum>`, delimiters `"}"` | parse.go (`unexpected`), https://raw.githubusercontent.com/prometheus/prometheus/main/promql/parser/lex.go (`Item.desc`, `Item.String`, `ItemTypeStr`) |
| checkAST messages: `binary expression must contain only scalar and instant vector types`; `comparisons between scalars must use BOOL modifier`; `bool modifier can only be used on comparison operators`; `set operator %q not allowed in binary scalar expression`; `vector selector must contain at least one non-empty matcher`; `metric name must not be set twice: %q or %q`; `expected type %s in %s, got %s`; `expected %d argument(s) in call to %q, got %d`; `expected at least/most %d argument(s) ...`; `no arguments for aggregate expression provided`; `wrong number of arguments for aggregate expression provided, expected %d, got %d`; `ranges only allowed for vector selectors`; `unary expression only allowed on expressions of type scalar or instant vector, got %q`; `offset modifier must be preceded by an instant vector selector or range vector selector or a subquery`; `@ modifier must be preceded by ...`; `unknown function with name %q`; `no expression found in input`; `duration must be greater than 0`; `trailing commas not allowed in function call args` | parse.go, generated_parser.y |
| Lexer messages: `unclosed left parenthesis`, `unclosed left bracket`, `unexpected right parenthesis %q`, `unexpected character: %q`, `unexpected character after '!': %q`, `bad number syntax: %q`, `bad number or duration syntax: %q`, `unterminated quoted string`, `unexpected end of input inside braces`, `unexpected character inside braces: %q`; keywords are matched case-insensitively (`strings.ToLower`); identifiers `[a-zA-Z_][a-zA-Z0-9_]*`, metric identifiers may contain `:`; numbers: decimal, exponent, hex `0x`, `inf`/`nan` case-insensitive, `_` separators | lex.go |
| Executed oracle (Prometheus v0.314.0) outputs for 129 parser inputs and 88 evaluator cases — copied into the draft's test tables | scratchpad/gocheck/out.txt |
